# Isis Aileen Pérez Rodríguez - Portafolio

Sitio web personal construido con HTML5 semántico, CSS3 moderno y JavaScript vanilla.

## Demo en vivo
[https://perezrodriguezisisaileen.github.io/portafolio/](https://perezrodriguezisisaileen.github.io/portafolio/)

## Características
- HTML5 semántico
- CSS3 con custom properties
- JavaScript ES6+ sin frameworks
- Paleta de colores verde
- Dark mode
- Formulario de contacto con validación
- Diseño responsive

## Tecnologías
- HTML5, CSS3 (Grid, Flexbox, custom properties)
- JavaScript ES6+
- Git y GitHub para control de versiones
- GitHub Pages para despliegue
